Zugang aufs Fernsehen schicken.
Von überall auf der Welt.

  • QR-Code scannen. Der Fernseher zeigt einen QR-Code, das Handy öffnet das Formular. Nie wieder Passwörter mit der Fernbedienung tippen.
  • Für Freunde in einem anderen Land. Den 10-stelligen Code per Nachricht schicken lassen, auf der Webseite oder in der App eingeben, fertig.
  • Ende-zu-Ende verschlüsselt. Xtream, M3U und Stalker verlassen das Gerät nur verschlüsselt. Der Code selbst wird nie übertragen.
  • Mit Rückmeldung. Du siehst live, wann der Fernseher die Daten hat und verbunden ist.

Installation auf Android TV
  1. Auf dem Fernseher die App Downloader (oder einen Dateimanager) installieren.
  2. In den Einstellungen „Apps aus unbekannten Quellen“ für diese App erlauben.
  3. Die APK-Adresse von dieser Seite öffnen, herunterladen, installieren.
  4. CinemaMax erscheint im Startbildschirm des Fernsehers.
Installation auf Linux 
chmod +x CinemaMax-*-x86_64.AppImage
./CinemaMax-*-x86_64.AppImage

# oder Ubuntu / Debian / Mint
sudo apt install ./cinemamax_*_amd64.deb
Installation auf Windows

ZIP entpacken und cinemamax.exe starten. Windows SmartScreen fragt beim ersten Start nach, weil die App nicht signiert ist: „Weitere Informationen“, dann „Trotzdem ausführen“.

FAQ

Gute Fragen.

Bringt CinemaMax Sender mit?

Nein. CinemaMax ist nur ein Player. Er spielt die freien, öffentlichen Listen von iptv-org und die Quellen ab, die du selbst einträgst. Nutze nur Quellen, zu deren Nutzung du berechtigt bist.

Was kostet die App?

Nichts. Keine Werbung, kein Abo, kein Tracking. Der Quellcode steht unter der MIT-Lizenz auf GitHub.

Ein Sender bleibt schwarz. Was tun?

Im Player auf „Info“ schauen und den Fehler lesen. Oft hilft in den Einstellungen ein anderer User-Agent oder der Player „mpv“ statt ExoPlayer. Bei Xtream-Live kannst du das Format zwischen MPEG-TS und HLS umschalten.

Wo bekomme ich einen TV-Guide her?

Bei Xtream kommt er automatisch. Bei M3U-Listen liest CinemaMax url-tvg aus dem Kopf der Liste. Sonst trägst du im Server-Menü eine eigene XMLTV-Adresse ein, auch als .gz.

Werden meine Zugangsdaten irgendwohin gesendet?

Nur an deinen eigenen Server. CinemaMax hat keinen eigenen Server und sammelt keine Daten. Alles bleibt auf deinem Gerät.

Läuft das auf meiner TV-Box?

Ab Android 7. Für schwache Boxen gibt es in den Einstellungen „Animationen reduzieren“ und die schnellere Videoausgabe „SurfaceView“.
