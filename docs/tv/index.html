An Fernseher senden

Zugangsdaten in Sekunden auf einen Fernseher bringen, auch zu Freunden in einem anderen Land. Ohne Tippen mit der Fernbedienung.

1Code vom Fernseher
Am Fernseher: Server hinzufügen → Per Code empfangen.
2Zugang
  1. Verschlüsselt
  2. Gesendet
  3. Am Fernseher angekommen
  4. Fernseher verbunden

🔒Ende-zu-Ende verschlüsselt. Die Daten werden auf diesem Gerät mit dem Code verschlüsselt und nur so über den Vermittler (ntfy.sh) übertragen. Der Code selbst verlässt dieses Gerät nie.
